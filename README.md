# SpreadsheetApp — Електронна таблиця

Навчальний проєкт настільного застосунку «Електронна таблиця» з розбором і обчисленням виразів у клітинках.
Виконано в межах **Лабораторної роботи № 1 (Варіант 31)** та **Лаб. 1\*** (інтеграція з Google Drive).

---

## Технологічний стек

- **Мова:** C# 13 / .NET 10
- **UI-фреймворк:** Avalonia UI (кросплатформний десктопний інтерфейс)
- **Архітектурний патерн:** MVVM (Model-View-ViewModel) на базі `CommunityToolkit.Mvvm`
- **Хмарне сховище:** `Google.Apis.Drive.v3` (OAuth 2.0 авторизація)
- **Тестування:** xUnit

---

## Особливості та можливості

1. **Обчислення виразів:**
   - Цілі числа довільної розрядності (`System.Numerics.BigInteger`);
   - Арифметичні операції: `+`, `-`, `*`, `/` (точне ділення), `div` (цілочисельне ділення), `mod` (остача від ділення);
   - Операції порівняння: `=`, `<`, `>`;
   - Логічні операції: `not`, `and`, `or`, константи `true` / `false`.
2. **Двоетапна обробка:**
   - Перший етап: синтаксичний аналіз (лексер та рекурсивний парсер) з точною локалізацією місця помилки;
   - Другий етап: топологічне сортування графа залежностей та обчислення значень.
3. **Граф залежностей та виявлення циклів:**
   - Підтримка посилань на інші клітинки (наприклад, `A1 + B2 * 2`);
   - Автоматичний каскадний перерахунок залежних клітинок при зміні даних;
   - Захист від зациклення: виявлення циклічних посилань (`CircularReference`).
4. **Режими відображення:**
   - Перемикач режимів `ВИРАЗ` (відображення введеної формули) та `ЗНАЧЕННЯ` (відображення обчисленого результату).
5. **Динамічна розмітка таблиці:**
   - Додавання та видалення рядків і стовпців зі збереженням структури та перерахунком.
6. **Збереження даних:**
   - Локальне збереження та завантаження таблиць у форматі JSON;
   - Хмарна синхронізація з **Google Drive** (відкриття списку файлів, створення та оновлення).
1. **Чиста архітектура:**
   - Повна відсутність бізнес-логіки в обробниках подій (code-behind містить лише `InitializeComponent`);
   - Усі дії користувача реалізовані через команди `[RelayCommand]` та прив'язки даних.

## Структура рішення

```
SpreadsheetApp.sln
├── docs/                      # UML-діаграми проєкту (class.puml, sequences.puml, usecase.puml)
├── src/
│   ├── Spreadsheet.Core/      # Ядро: Лексер, Парсер, AST, Обчислювач, Граф залежностей, Модель
│   ├── Spreadsheet.Storage/   # Робота зі сховищем: LocalFileStorage, GoogleDriveStorage, CompositeStorage
│   ├── Spreadsheet.ViewModels/# ViewModels, команди, локалізовані ресурси та абстракції діалогів
│   └── Spreadsheet.App/       # Avalonia UI: вікна, розмітка, стилі та прив'язки
└── tests/
    └── Spreadsheet.Core.Tests/# Юніт-тести бізнес-логіки ядра (xUnit)
```
